# Stallone Msamba Portfolio

A responsive personal portfolio website for AI Training & Evaluation, digital transformation, research and business experience.

## Files
- `index.html` — portfolio content
- `style.css` — responsive design
- `script.js` — mobile navigation
- `assets/Stallone-Msamba-CV.pdf` — add your final CV here

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your email.
2. Replace `YOUR-LINKEDIN` with your actual LinkedIn profile slug.
3. Add your CV as `assets/Stallone-Msamba-CV.pdf`.
4. Review project/research descriptions and update any details you want.
5. Commit the files to a GitHub repository and enable GitHub Pages.

## GitHub Pages
Repository Settings → Pages → Deploy from a branch → select `main` → `/ (root)` → Save.
